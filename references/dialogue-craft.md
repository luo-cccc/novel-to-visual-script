# 对白、声音与情绪外化

写或改对白、处理情绪戏时读取。和 [visual-scene-craft.md](visual-scene-craft.md) 的“对白、声音与停顿”配合使用；A 档保留原对白时，只修听不懂、念不出的地方。

## 硬约束

- **人物只回应自己听见、看见、知道的东西。** 回应未听见的台词，或者用到观众知道而人物不知道的信息，就是越过了知识边界。人物说出前场的事实时，查一下他当时在不在场；不在场，就要有一个观众看得到或听得到的来源（有人告诉他、他看到了痕迹），否则改成怀疑、猜测或提问；猜测可以猜错。看不见的人不能说出只有眼睛才能得知的事。设定内的超自然知情（预知、读心之类）不算越界，但正文要让它作为异样被其他人物或观众察觉，而不是悄悄当作常识用。
- **每句台词都在对某人做某事。** 试探、拖延、逼问、讨好、示弱、羞辱、转移都算。说不出它在做什么的台词，删掉，或者改成动作。
- **对白不复述画面。** 观众已经看到的，人物不再说一遍；需要说的时候，要说出画面里没有的态度。
- **声音来自人物处境，不来自装饰。** 不按人数平均分配口头禅、方言词或怪癖。

## 开口前先定七件事

关键人物在关键场次开口前，心里先有答案，不必写进正文：

| 项 | 问题 |
| --- | --- |
| 关系 | 他和对方现在是什么关系，欠什么、怕什么 |
| 目的 | 这一场他想让对方做什么、相信什么、放弃什么 |
| 所知 | 他知道多少，误信什么，以为对方知道多少 |
| 风险 | 说错一句会失去什么 |
| 场合 | 谁在旁边听，能不能大声，能说多久 |
| 身体与时间 | 累、痛、饿、醉、赶时间，手里在干什么 |
| 习惯 | 身份、年龄、地域、职业带来的用词与句长 |

七项里，目的和风险决定说什么，场合和身体决定怎么说，习惯只决定措辞。

## 潜台词

人物不肯或不能直说时，用下面四种方式绕开，观众仍要能读出真意：

- **转移话题**：被问到痛处，去说一件不相干的小事。
- **以问代答**：用反问把压力推回去。
- **借物说事**：说饭、说天气、说一件旧东西，其实在说两人的关系。
- **沉默或动作**：不回答，去做一件让对方看得见的事。

潜台词要有可读的锚点：前文成立的旧事、物件或关系。没有锚点的含糊只是含糊。必要信息、紧急处境和性格直率的人可以直说，不强求每句都绕。

## 权力与交锋

对白里的地位靠这些动作显示：谁提问、谁回答，谁回避、谁打断，谁先沉默，谁决定话题结束。一场交锋中，至少有一次权力发生转移，或者一方试图转移而失败；否则这场戏只是在交换信息。

- 信息是弹药：背景、旧账、秘密只在能伤人、能换东西、能逼对方表态时才说出来。
- 谎言多数是大半真话加一处篡改；被追问时，说谎的人补细节、改话题或反咬，而不是突然坦白。
- 两人僵住时，可以引入第三人：当着外人不能说的话、借骂第三人出的气，都会改变说法。
- 句子的重心放在句尾。最要紧的字眼、最伤人的那个词，留到最后说出来。
- 打断用“——”标出，被打断的半句话也要让观众猜得出原本要说什么。

## 声音区分

- **遮名测试**：遮住人名读一场戏，主要人物要能认出谁在说。
- **换人测试**：把一句台词换给另一个人说仍然成立，这句话往往没有立场，只是信息。
- 区分来自：句子长短、用不用敬称、先说结论还是先绕、爱用具体名词还是抽象词、生气时变多还是变少、绝不会说出口的话。
- 每个主要人物定一两条“绝不会说的话”或“绝不会提的事”，交锋时让这些边界被逼近。
- 方言、行话和时代用语点到即可，观众听不懂就要能从回应和动作里明白。
- 人物的标志性说话方式（如天真人物的字面理解、反问）不要整部戏只用一种手法：它要随关系和处境变化，至少有一次被逼到用不出来。

## 台词禁区

以下写法会让人物变成念说明的工具，正文里出现就改：

| 禁区 | 表现 | 改法 |
| --- | --- | --- |
| 说明书式独白 | 独处时把计划、规则、心理逐条讲出 | 改成行动，或改成对另一个人有目的的话 |
| 互相复述已知 | “你也知道，我们三年前……” | 删掉；确需交代时让一方用旧事攻击另一方 |
| 捧哏式惊叹 | 配角只负责说“什么？！”“竟然是你！” | 让配角有自己的利益和反应 |
| 潜台词直译 | “其实我是在害怕失去你” | 换成四种潜台词之一 |
| 情绪播报 | “我现在非常愤怒” | 用动作、停顿、话变短来呈现 |
| 金句堆叠 | 每场都有总结人生的格言 | 格言必须由处境逼出来；同一场出现第二句时，查它是不是在替场面下结论，是就删 |
| 万能回应 | 换谁说都成立的“我明白”“没事的” | 写出这个人此刻特有的回避或要求 |

## 情绪外化

先确认这场戏观众需要读懂什么情绪，再选能拍到、能听到的表现。下表是常用方向，不是替换词典：

| 情绪 | 可拍、可听的表现 |
| --- | --- |
| 压着的愤怒 | 话变少变短；动作变精确，摆正本来就正的东西；称呼变得客气 |
| 恐惧 | 先确认出口和距离；声音放低；手找东西抓或藏 |
| 羞耻 | 避开对方的眼睛却不离开；替自己找事做；笑得不合时宜 |
| 悲伤 | 照常做日常的事，在某个小环节停住；不该被留下的东西被留下 |
| 思念 | 为不在的人多准备一份；习惯性地叫出名字又停住 |
| 心动 | 注意力被对方的小细节牵走；平时不做的事为对方做了 |
| 决心 | 把退路处理掉：还清、送走、烧掉、签字 |

**二次动作**最可靠：动作做了一半停住、收回或改向。伸手去扶又缩回，拨号拨到最后一位挂断，端起碗又放下。停住的那一下就是内心戏。

同一个反应别反复用。“攥紧拳头”“倒吸一口凉气”“瞳孔一缩”一类惯用反应，在同一集或同一幕里重复出现时，查第二次有没有新的作用；没有，就换成这个人物特有的动作。

## 改前与改后

**例一：说明书式对白 → 用旧事攻击**

改前：

```text
陶芸
你也知道，三年前你爸生病，是我一个人照顾的，你一次都没回来。

骆川
我知道，那时候我工作很忙，我很内疚。
```

改后：

```text
陶芸把一份卖房委托书推到骆川面前，上面压着一张旧护工表，折过很多次。

陶芸
中介下午就来。签个字。你爸住院那年，这张表上家属一栏一直空着。

骆川拿起笔，看见那一栏里有人用铅笔写过他的名字，又擦掉了。

骆川
……谁写的？

陶芸
护士。她以为你会来。
```

两人的关系、旧账和内疚都在，变成了一次逼他签字的行动：签字有当下的理由，旧账由物件交出。

**例二：情绪播报 → 二次动作**

改前：

```text
郑禾
（哽咽）我好想她。我每天都在想她。
```

改后：

```text
郑禾盛了两碗面。第二碗端到半空，停住了。她把它放在对面的位置上，摆好筷子，坐下，先吃自己那碗。
```

**例三：可以不改**

```text
程野
门锁了。

孟知遥
窗。

程野
三楼。

孟知遥
那就三楼。
```

追逃中的短句，信息直给、节奏紧，人物态度也清楚。这里不需要加潜台词或动作描写，强行“丰富”反而拖慢节奏。
