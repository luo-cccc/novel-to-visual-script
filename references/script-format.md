# 最终剧本格式

用户已有格式时沿用。否则采用适合阅读和后续制作的中文文学剧本：

```text
《作品名》

主要人物（确有理解需要时）：
人物名——可在当前范围公开的身份或关系。

01  内景  维修铺  夜

林遥把修好的旧收音机放到柜台上。店主插上电源，没有声音。

林遥伸手要拿回去。店主先把插头按到底。

店主
再试一次。

林遥转动旋钮。杂音响起，她的手停在旋钮上。
```

上例仅演示排版，不预设题材和文风。

## 实际交付要求

- 用场次序号、内外景、地点和时间识别时空，格式保持一致。
- 动作写当下可感知的事件，段落按阅读节奏组织；不要给每个动作加“镜头切到”。
- 对白由人物名引出。电话、画外音、内心独白等确有需要时简要注明，避免满篇情绪和表演指令。
- 转场、回忆、主观段落只在影响理解时标明。不要因为格式清楚而提前泄露隐藏身份。
- 台词、动作和现场关系共同讲清剧情。没有演出来的重要事件，不能只在人物表或“剧情说明”中交代后算完成。
- 不默认加入逐镜时长、摄影参数、视频提示词、评分、通过标记和场景卡。
- 没有给定时长时不声称精确片长。确需估计时明确其依赖表演、停顿和剪辑；用户给定体量时据此裁剪场面，不机械按字数或对白句数换算。

## 分批与说明

改编节选时，可在标题下用一行注明本批实际范围。长篇因交付容量分批时明确停止位置，随后提供或保存精简承接记录。不要把未完成内容标为完整剧本。

用户要求改编对照时，另附简短记录：实际保留的核心和机制、重要重构及其作用、原文未提供或仍待确认的信息。对应具体场面，不空泛宣称“更有电影感”。默认不展示推演过程。

返修按用户要求交完整更新稿或需要替换的完整场次。局部替换稿标明原场次及替换范围，保留可定位的编号与衔接，不能只给“此处改成更主动”之类建议；用户要全稿时，也不能让其自行拼接片段。

用户明确要求 Fountain 时，使用其场景标题、人物和对白语法，并保持故事内容及信息边界一致。用户要求 Word、PDF 等成品文件时，再使用相应可用文档能力，不假定本技能自带排版或编译工具。
