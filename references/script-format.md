# 最终剧本格式

用户已有格式时沿用，否则交付中文文学剧本：

```text
《作品名》

主要人物（确有理解需要时）：
人物名——可在当前范围公开的身份或关系。

01  内景  维修铺  夜

林遥把修好的旧收音机放到柜台上。店主插上电源。

店主
试试。

林遥转动旋钮。杂音响起，她的手停在旋钮上。
```

示例仅演示排版，不预设题材和文风。

## 实际交付要求

- 标题后按需列主要人物，只公开当前范围可知的身份与关系。
- 场次统一使用序号、内外景、地点和时间；人物表、场景标题、正文及画面文字使用同一套名称与设定，别称和引用同步更新。
- 人物名引出对白；电话、画外音、内心独白及影响理解的转场、回忆或主观段落简要注明，避免标注泄露悬念。
- 默认交付正文。场面写法见 [visual-scene-craft.md](visual-scene-craft.md)，分镜、生成提示词和制作参数按另行要求处理。
- 估计片长时说明其依赖表演、停顿和剪辑；按指定体量裁剪，不把字数或对白句数机械换算成时长。

## 分批与说明

节选或分批稿在标题下注明实际范围和停止位置，承接记录另存或精简附后；未完成内容不标为完整剧本。

要求改编对照时，简述保留项、关键重构及其新场面落点、尚未提供或待确认的信息，不展示推演过程或用改动比例证明质量。

返修按要求交完整更新稿或完整替换场次。替换稿标明原场次、范围及衔接，不只给修改建议；要求全稿时交整稿。

要求 Fountain 时使用其场景、人物和对白语法；要求 Word、PDF 时使用相应可用文档能力，格式转换保持内容与信息边界一致。
