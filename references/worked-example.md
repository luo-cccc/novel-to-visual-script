# 完整示例：《画皮》保核重构

用公版作品《聊斋志异·画皮》演示 C 档从提取到正文的全过程，并附反例。示例中的判断是一种可行解，不是唯一答案；新故事的题材和文风也不预设到其他任务上。

## 原作要点

太原王生路遇独行美女，带回家藏在书房。妻子陈氏劝他送走，他不听。道士说他身上有邪气，他也不信。后来他偷看到恶鬼铺开人皮、执笔描画，才惊恐求救。道士给他一柄拂尘挂在门上，恶鬼撕碎拂尘，剖开他的胸膛取走了心。道士除掉恶鬼后说自己无法起死回生，只能指点陈氏去求市上的疯乞丐。陈氏当众受辱，吞下乞丐的痰，回家后伏尸痛哭，痰化作心落入丈夫胸腔，王生复活。

## 写前改编卡

```text
档位：C 保核重构（用户未指定）
锁定项：无
核心类型与必保条件：惊悚 + 救赎。
  - 伪装完美，致命之处藏在受害者自己的欲望里；
  - 警告存在，却被欲望压过；
  - 救命的代价不由犯错的人承担，而落在爱他的人身上，且以屈辱支付，事先没有成功的保证。
必保机制：
  - 伪装需要定期维护，维护失败就会显形（对象：伪装者；触发：维护中断）；
  - 受害者失去生命，但存在一个有限时间内的挽回窗口；
  - 挽回权在第三方手里，条件由第三方提出，救人者无法讨价还价。
名称与载体映射：
  王生 → 宋怀山（退休扳道工）；陈氏的“救人者”功能 → 儿子宋迟；
  恶鬼/人皮 → 阿檀/每夜泡在冷水里养着的脸；
  道士 → 拆成两人：警告者老冯（锅炉房，哑），挽回者尤德顺（收旧货）；
  拂尘 → 删除；痰化心 → 删除；太原 → 北方小城铁路家属院，2000 年前后。
新设定：家属院共用楼顶水箱，阀门谁都能关；邻里关系紧密，旧账人人记得。
角色功能分配：
  - 原道士的“警告/给护身物/杀鬼/指点”拆开：警告给老冯，指点并入老冯，护身物和杀鬼删除；
  - 挽回者从陌生疯人改为与受害者有旧仇的人。
新事件链决定节点：
  ① 丧妻独居、与儿子断联的宋怀山收留“寻亲扑空”的阿檀，阿檀把他当父亲伺候；
  ② 老冯写字警告，宋怀山撕了字条；他对阿檀说“你别走，我这条老命都给你”；
  ③ 宋迟回家，以为阿檀是骗房子的，关掉水箱阀门想逼她走；
  ④ 早饭时阿檀的脸当着父子的面干裂，宋怀山看清了，仍然选择她，命令儿子开阀；
  ⑤ 宋迟当着阿檀的面揭穿她、轰她走；阿檀离开前取走“说好的”东西，宋怀山没了气息，身体却不凉；
  ⑥ 老冯指点：只有当年被宋怀山举报而丢了工作的尤德顺懂这个；
  ⑦ 尤德顺的条件：宋迟跪在家属院公告栏前，替父亲把当年的举报信当众念完；
  ⑧ 念完最后一个字，宋怀山在家中醒来；
  ⑨ 全院都知道了旧事，宋怀山没法再住下去，坐上儿子的货车离开。路过收购站时，他下了车。
去标签对照：见下表。
未知项与待确认：无。
```

## 去标签对照

| 维度 | 原作 | 新稿 | 为何不同 |
| --- | --- | --- | --- |
| 决定节点 | 偷看到真相后恐惧求救 | 当面看清真相后，仍然选择伪装者 | 欲望在看清之后依然胜出，转折方向相反 |
| 关系网 | 夫妻 + 外来女色 + 道士 | 断联的父子 + 扮演女儿的伪装者 + 旧仇人 | 诱惑从色欲改为“被需要”；救人者同时是被冷落的人 |
| 信息揭示 | 受害者独自偷看 | 由儿子的世俗怀疑间接引发，三人同时在场 | 揭示的途径和人物知识结构都不同 |
| 解决方式 | 道士杀鬼；救人者吞秽物，化为心 | 伪装者自行离去；救人者替父亲公开认罪，复活发生在异地 | 屈辱的性质从身体改为名誉；救人者不在复活现场 |
| 结尾 | 复活即止 | 复活的代价是名誉永久受损，父亲主动走向旧仇人 | 结尾以受害者的新行为兑现 |

保住的是类型的共有结构（伪装、警告、代价、救赎），这一层允许保留。

## 正文片段

```text
07  内景  宋家厨房  晨

水龙头拧到底，只响了一声空气。

阿檀把水龙头拧回去。灶上的疙瘩汤咕嘟着。她侧着脸搅锅，左颊有几道细纹，像旧瓷上的开片。

宋怀山坐在桌边剥蒜。宋迟靠在门框上，手里攥着一把扳手，上面沾着铁锈。

宋怀山
水怎么停了？

宋迟
楼顶阀门坏了。我下午去看。

阿檀把汤端上桌。细纹已经爬到眼角。她低头的时候，一小片皮从颧骨上翘起来，落进碗里。

宋怀山看着那片东西漂在汤面上。

他抬头。阿檀的颧骨上缺了一块，底下不是肉，是一个干涸的黑洞。

宋迟往前走了一步。

宋迟
爸。你看清楚。

宋怀山用筷子把那片皮从汤里夹出来，放在自己的手心，递给阿檀。

阿檀没接。

宋怀山
（对宋迟）
阀门打开。

宋迟
她不是人。

宋怀山
她每天给我做饭。你三年没回来。

他把那片皮按回阿檀的颧骨上，手指停在那里。

宋怀山
打开。
```

这场戏用到的条件都在前场成立了：水箱阀门谁都能关（03 场）；阿檀每晚锁着门在浴室待很久，换下的水冰凉（04 场）；宋怀山许下“这条命给你”（05 场）。场中出现的能力没有超出这些条件。

## 反例

**反例一：只换了名字。** 江南书生林墨收留落难女子，藏在书房；妻子劝他，相士警告他；他半夜偷看到女鬼对镜描脸；相士给他一面铜镜，女鬼砸碎铜镜，掏走了心；妻子去求街头疯汉，受辱，吞下符纸，回家后符纸化为心。
问题：去掉名称后，每个决定节点都能逐项对回原作，换掉的只是载体。

**反例二：偷加能力。** 宋迟开车时从后视镜里看到阿檀的真身，原来货车镜子能照妖；他拿镜子照她，阿檀当场化成灰。
问题：照妖能力没有任何铺垫，核心冲突靠临时外挂解决；救赎的代价也因此被绕开了。

**反例三：结尾只换了旧物的名字。** 宋迟念完信回家，伏在父亲胸口痛哭，喉咙里涌出一团热东西，落进父亲胸口，父亲睁开眼。
问题：这是原作“痰化心”的画面换了说法，结尾没有来自新人物经历的兑现。

**反例四：永久代价被抵消。** 尾声里邻居们表示理解，尤德顺撕掉公告，父子留在家属院，日子照旧。
问题：名誉受损的代价被事后一笔勾销，救赎的分量随之消失。
