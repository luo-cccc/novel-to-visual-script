# 从小说叙述到可感知场面

按场面需要选用以下方法。忠实改编和局部返修遵循用户指定的保留项与范围。

## 硬约束

- **观众只能从画面、声音和文字得知信息。** 没写进正文的心理、动机和规则，对观众来说不存在。
- **对手和配角按自己的所知与利益行动。** 靠对方降智推进，主角的胜利就不值钱。
- **高潮用到的条件要先成立。** 解局后才补说明，观众会觉得被骗。
- **人物、位置和物件状态连续。** 状态跳变会让观众出戏，也会破坏推理和动作的可信度。

## 人物行动与关系

先判断观众需要知道多少心理信息才能理解人物的选择。需要外化时，写人物在压力下试探谁、避开什么、愿意交出什么、选择不做什么，让行为有对象、有回应；沉默或不行动也可以是回应。小动作、提问和分析句，只有在改变了策略、信息、成本或对方行为时才算主动。新增行为要兼容保留事实与已采用设定，比如为了表现怀疑，不能凭空添出确凿罪证。

关键交锋按双方的目标、所知、资源与底线推进。主角使用机制前后的判断要影响结果；对手为什么接受、为什么不能拒绝、为什么来不及阻止，也要成立。误判可以来自对手的所知、情绪或利益。

重要关系里，双方各有当下的诉求与回应。信任、疏离、歉疚与和解，靠互动和之后的行为变化来成立；代价要实际影响选择、相处或后续生活。保留情感功能，不要求沿用原来的救助关系或相处方式。

## 规则、信息与悬念

规则通过当前选择所需的说明、触发、反馈或失败来呈现。关键触发由已有的目标、危险、选择或关系引出，所需条件先在场面里成立；代价按规则结算，不在高潮临时制造事故来结算。反馈媒介和外观可以改，信息能力和规则语义按 [mechanism-contract.md](mechanism-contract.md) 保持。

必要的契约、口令、告示和系统文字可以直接出现，让说明和后果一起把选择讲清楚。影响剧情的道具，要交代它的控制、流转、用途与损失；普通装饰不必都变成伏笔。

- **分清证据、人物解释与客观事实。** 推理要写出观察、验证和反馈，不能摆完线索就直接报答案。
- **分清私人发现、行动依据与服众证明。** 能力或推断可以指导主角寻找、避险和试探；需要旁人配合或追责时，给出对方能理解或复核的依据，以及符合其利益、处境或权限的行动理由。
- **保持人物与观众的信息渠道。** 谜底可以未知，但当前行动的目的和改变策略的缘由要能看懂；补衔接不能变成提前揭露真相。
- **回忆、梦境、幻觉、设想和不可靠叙述要让观看层次可辨。** 不用全知画面坐实猜测，标注本身也不能泄露悬念。

### 场次知识表

悬疑、多方隐瞒或信息差推动的场次，写前在心里过一遍，不写进正文：

```text
场次：
进场时  人物甲：确知 / 怀疑 / 误信    人物乙：……    观众：……
本场的信息操作：（揭示 / 隐瞒 / 误导 / 证实 / 推翻 / 转交）
出场时  人物甲：……    人物乙：……    观众：……
```

出场时没有任何一栏发生变化的场次，要么承担别的功能（关系、代价、余波），要么并掉。人物的“确知”只能来自他在场看到、听到的，或者来自正文里出现过的转告；没有来源的写成“怀疑”。设定内的超自然知情另记一栏，并在正文里让人察觉它的异样。长篇时，出场状态写进承接记录的“人物知识状态”。

### 信息差的四种用法

| 用法 | 谁先知道 | 观众的体验 |
| --- | --- | --- |
| 悬念 | 观众知道危险，人物不知道 | 替人物紧张，等它爆开 |
| 戏剧反讽 | 观众知道真相，人物在误信里行动 | 看人物说出意味相反的话 |
| 谜题 | 人物和观众都不知道 | 跟着找答案 |
| 惊奇 | 人物知道而观众不知道 | 揭开时重读前文 |

同一个秘密可以先后换用几种。规划时分清三个时间点：观众何时知道、关键人物何时知道、何时公开。信息差被打破的那一刻要有实际后果，改变关系、资源或下一步行动；揭开后什么都没变，就是虚假悬念。

惊奇要能回看成立：揭开后，前文至少有几处画面或台词因此有了新的意思，而且当时并没有骗观众。

## 对白、声音与停顿

C、D 档的对白按新人物的目的、所知、关系、身份处境与语感重写。区分人物能说什么、不愿承认什么、想让谁改变什么；不靠近义替换或口头禅制造差异。下一句话或下一个动作要回应刚发生的刺激。必要信息可以直说，不强求每句话都有潜台词。潜台词、权力交锋、声音区分、台词禁区与情绪外化的具体方法见 [dialogue-craft.md](dialogue-craft.md)。

声音可以承担空间、危险、身份和节奏信息。无法准确外化的内心选择，可以用有功能的独白或画外音。删去重复画面的说明，以及替缺席的行动收尾的说明；紧急处境里的长解释要有时间和理由。

给听见之后的反应、决定之前的停顿、失败之后的余波留出位置。节奏随事件与表演组织，不按对白句数、固定占比或统一秒数安排。

## 场面、动作与收束

场面从已重构的人物与冲突展开。重要交锋造成的信息暴露、资源损耗、关系变化或新机会，要进入下一步选择。高潮依靠的资源、能力边界与操作条件，先在前文或当前行动里成立；核心冲突由人物的选择解决，不能让无铺垫的救援、故障或偶发帮助独自解决。允许铺垫、过渡和余波，不要求每场都有翻转。

- **晚进早出**：从冲突已经在场的那一刻进场，在局面改变后尽快离场；寒暄、进门、落座和告别，除非承担关系信息，否则省掉。
- **场与场之间是“于是”或“但是”**：上一场的结果逼出下一场的行动，或者打断它。只能用“与此同时”连接的场次，检查它是否在推动主线。
- **封死退路**：人物冒险、受辱或付出代价之前，观众要看到更省事的路已经走不通（试过、被拒、来不及、代价更大）。否则观众会问“他为什么不直接……”。
- **对手按自保行事**：对手察觉威胁时会做理性的自保动作：转移证据、先下手、找靠山、拖时间，而且不会亲手留下指向自己的证据。主角的胜利要越过这些动作，不能靠对手忘了做。

动作按观看顺序与注意力组织；一段可以容纳一个行为、一个反应或一次完整交互，不等于逐镜编号。空间与操作只写理解结果所需的条件：距离、通路、遮挡、双手占用、时间、设施运作和他人阻拦。人物不能同时完成相互排斥的动作。

打斗、逃跑和群戏围绕目标、策略、阻碍与结果来写，不堆小动作或机械步骤。有明确的制作限制时，找能保住剧情功能的替代表现。

结尾用新的行为、关系变化或后续生活来兑现情感。标志性意象来自新环境与人物经历，不能只把原结尾的旧物换个名字；含蓄的代价与余波也要有正文依据。

### 压缩与扩展

原作篇幅与目标体量不符时，按下面的顺序取用，取舍写进交付说明：

1. **提炼**：每章或每段只问“这里必须完成的那一件事是什么”，其余是候选删减。
2. **并场**：发生在不同地点、功能相近的两场，合到一个地点一次完成。
3. **并人**：功能相近的配角合成一个，保留必要的证据独立性与信息边界。
4. **三次法则**：反复出现的母题或关系变化，保留建立、升级、兑现三次，中间重复的删去。
5. **前移**：后文才起作用的条件、人物或物件，提前到开头附近的场面里自然出现，减少专门的交代场。

扩展时补的是处境、阻碍、代价和后续生活，不补无关支线。A 档只做不改变事件和人物的压缩：可以提炼、并场和删去重复，不并人，前移也不能改变事件发生的先后；删合场次在交付说明里列出。

## 正文审读

只凭当前正文，核对事件为什么此刻发生、人物如何选择、观众从哪个画面或声音理解，以及场面之后改变了什么。缺口回到正文修复，不从原文答案或附录补齐。

需要独立审读时，审读者只看当前剧本和必要的无剧透背景。反馈要分清：事实、猜测、妨碍跟随行动的缺口、值得保留的未知。写作者核对正文证据后，决定是修复还是保留悬念。反馈注明是模拟阅读，不代表真实受众，也不自动覆盖用户的保留项。

两个诊断方法：暂时忽略对白，只看行为和关系是否成立；再只看对白，检查它是否一直在解释画面。静音检查只用于诊断，不能据此删掉承担关键叙事的声音和语言。

## 模型常见失败

生成式写作有一些稳定的倾向。审读时逐项找，找到就回到场面里修，不靠替换词语掩盖：

| 失败 | 表现 | 修法 |
| --- | --- | --- |
| 提前化解张力 | 冲突刚起，下一句就有人让步、道歉或讲和 | 让双方各自坚持到出现真实代价 |
| 场面写成概述 | “两人争执了很久，最终……” | 写出争执中改变局势的那一两个回合 |
| 角色同质化 | 人人说话一样有分寸、一样会总结 | 按 [dialogue-craft.md](dialogue-craft.md) 做遮名测试 |
| 叙述者评论情绪 | 动作后补一句“这让她感到绝望” | 删掉评论，相信动作 |
| 消解歧义 | 把本应留白的动机、关系、结尾解释清楚 | 保留正文证据，删掉解释 |
| 人人都配合 | 对手、配角轻易接受主角的说法，没有自己的利益 | 让他们按自己的所知和利益要价、拒绝或拖延 |
| 对称收束 | 每场都以感悟、承诺或一句金句结束 | 停在局面变化处，或停在一个动作上 |
| 惯用反应堆叠 | 攥拳、深吸一口气、眼眶泛红反复出现 | 换成这个人物特有的动作，或直接删掉 |
| 翻案句式 | 频繁出现“不是……而是……”“与其说……不如说……” | 直接写出那个“而是”的内容 |
| 意象过载 | 一段里多个比喻，修辞和人物处境无关 | 意象取自人物所在的环境；一处叠了几个时，只留和人物处境有关的那个 |

这张表是审读时的提示，不是禁词表：人物台词里出现“不是……而是……”可能正是他的说话方式。判断标准始终是这个写法在场面里是否有功能。
