# 故事核心、机制与重构

## 硬约束

- **锁定项不动**：用户明确要保留的内容照办；新约定替代旧约定。
- **必保机制的语义不变**：对象、触发、次数、代价、限制与解除条件不变，外观可以换。改了语义，原作“为什么好看”就丢了。
- **不靠扩大能力保住原动作**：换设定后原动作做不成时，改动作，不加能力。
- **永久代价保持永久**：分量来自不可逆。
- **未知保持未知**：未核对的后文不能当作事实使用。

## 四层保留项

按优先级从高到低：

1. **锁定项**：用户指定保留的人物、关系、事件、规则、结局或表达。A 档默认锁定主要人物、名称、主要事件与结局。
2. **核心**：读者追看的情感压力、吸引力类型和回报性质。通过新冲突中的选择和后果实现，不锁死原来的亲属结构、职业、愿望对象或结尾画面。
3. **机制**：让核心选择与回报成立的必要条件，包括能力、资源、关系、信息与利益约束。只保住必要条件，不把原作的每笔交易、每段关系都当成不可变。D 档可以重设机制，只要新机制实现同类核心。
4. **实现**：姓名、人物组合、物件、地点、对立关系、具体事件、场序和表达。C、D 档全部重做。

区分原文事实、角色口述、猜测、推断和新增改编。

## 核心类型与必保条件

先判断原作靠什么吸引人，可以是多种类型的组合，以主导类型为准。

| 类型 | 必保条件 | 常见失败 |
| --- | --- | --- |
| 逆袭 / 爽感 | 压制真实且有代价；翻盘靠已铺垫的筹码或成长；对手按自身利益行事 | 对手降智；翻盘靠临时外挂；压制只停留在口头 |
| 悬疑 / 推理 | 线索对观众公平；信息按设计释放；推理有观察、验证与反馈 | 答案直接报出；全知画面坐实猜测；标注泄底 |
| 规则 / 怪谈 / 系统 | 规则先于使用成立；代价在关键时刻照样结算；规则自身的陷阱在起作用（不要求原作为主角准备一个可钻的漏洞） | 高潮时临时加例外；代价被事后抵消 |
| 虐恋 / 救赎 | 双方各有诉求；代价真实影响相处与后续生活；和解要用行为换来 | 误会靠不说话硬撑；代价在结尾一笔勾销 |
| 成长 / 群像 | 选择逐步改变人物；关系变化可见；每个主要人物有自己的诉求 | 成长只体现在台词上；配角只是工具 |
| 惊悚 / 生存 | 威胁规则一致；资源有限并会持续消耗；逃生依靠前面交代过的条件 | 威胁忽强忽弱；靠偶然获救 |
| 奇观 / 设定 | 设定影响人物选择；奇观服务于冲突 | 设定只是背景板；说明堆在台词里 |

## 机制核对

只记录影响本次改编的条件及可定位来源：

- **规则**：对象、触发、次数、反馈、限制与解除条件。“对象”指机制作用在谁身上、代价由谁承担，不是指承载它的那件东西。
- **信息**：种类、精度、时间范围；人物和观众各知道什么。
- **代价**：谁承担、能否恢复、回报怎样兑现。
- **依赖**：前后事件之间的依赖关系。

**载体的附带属性**（是否便携、在什么环境里操作）随载体更换而变，不算受保护的“限制”。但换载体后新出现的空间或操作约束不能被忽略：原剧情每处使用都要在新载体下仍然成立，不成立就改行动，不加豁免。

**源作的量化单位与呈现不一致时**（例如说“付三天”，实际失去的是一整段日子），以文本真正呈现的后果为准：保住“不可逆”和“代价随次数递增或累积”的语义，不机械对齐数字。正文里要么让这套算术站得住，要么让人物明确不计较它；不能靠含糊叙述绕过。

没有页码或章节号时用独特事件定位，不编造引文。信息顺序为知识边界和悬念服务，不必锁死原著时间线。

换载体时分开看：

- 反馈媒介、感官表现和操作外观**可以换**；信息能力、触发条件与代价**不能变**。
- 不能为了画面具体，多给身份、时间或完整真相。比如原作只能听到声音，改成“看到画面”就是多给了信息。
- 以下几组是不同的条件，要分别成立：
  - 证据**取得**与证据**生效**；
  - 能力**获得**与能力**可用范围**；
  - **受损**与**恢复**。
- 必要的证据独立性可以用新来源重建，不必保留原来的配角数量。

明确的永久损失，用不可撤销的选择、持续失效、规则结算或后续生活来呈现，不限定为某种解释台词。

原文说法不兼容时，先分辨是不可靠口述、尚未揭示的例外，还是真正的冲突。在授权范围内做最小兼容；仍影响核心又无法兼容的，指出具体问题，不偷偷增设有利规则。

## 修复原作缺陷

在不违背锁定项的前提下，可以修复原作的因果漏洞、注水、降智推进、工具化配角和前后矛盾，修复方式按新设定重建。A 档只做最小修复，并在交付说明里列出。不借“修复”之名改动核心或必保机制。

## 名称、角色与载体

C、D 档替换人物姓名与别称、地点、组织、关键物品和标志性设定名，统一新稿里的称呼与引用。关键物品和地点要同时更换具体载体，让外观、用途、空间和使用条件适合新故事。普通通用名词不必逐词替换。A 档沿用原名称；B 档只替换外层名称与地名，不改事件。

**命名规则**：

- 不用原名的谐音、近形字、拆字、同义改写或拼音缩写。
- 不撞名人、知名作品角色或真实机构。
- 符合新设定的时代、地域与阶层。
- 主要人物之间首字、读音和字数拉开差距，方便观众区分。同一场里出现、或需要观众记住其立场和功能的角色，都算在内；纯粹报信、过场的一句路人可以同姓同名式处理。
- 名字可以有寓意，但不能直接剧透身份或结局。

名称记录服务于一致性，不要求人物和功能一一对应。可以合并、拆分或重新分配知情、阻碍、帮助、作证等功能，并按新冲突重组依赖、欠债、利益和权力，同时保留必要的独立性与信息边界。

姓名、职业、物件或地点承担谜题、证据或触发作用时，在替代设定里重建这些条件，线索、判断和后果一起改。换行业、时代或载体后，权力、资源与解决手段要在新环境里成立。作品新增的制度按作品内约定呈现。

## 重建冲突与事件链

从新人物的目标、资源和约束生成冲突：各方争取什么、为什么不能兼得、为什么此刻处理、有哪些退路和筹码。策略要改变下一步的选择与代价；对方按其所知和利益回应，不能突然失智或无缘无故退让。

场面可以压缩、扩展、合并、删减或重写；新增的行动与线索要兼容保留项和已采用设定。已授权的换名、换物、换景与冲突重构直接完成，不逐项请示。

### 去标签比较（C、D 档）

去掉人名、地名与物品标签后，逐项比较：

- **决定节点**：局势在哪里转折，靠什么转折。
- **关系网**：人物之间的利益、依赖、亲疏结构，以及谁帮谁、谁背叛谁。
- **信息揭示**：谁在何时以何种方式得知什么。
- **解决方式与结尾**：核心冲突怎样解决，最后落在什么行为和画面上。

任一维度仍能逐项对回原作的，重做该维度上决定局势的节点。判定按这个顺序走：先看**决定节点**是否同因同果（转折的理由、筹码和代价是否一样）；再看**关系网**是否只是换了人名；再看**信息揭示**的顺序与渠道；最后看**解决方式与结尾**是否落回同类画面。只交换场序不改变因果，不算重构。机制必要步骤和类型共有的结构可以保留；不用相似率、固定改动数或刻意打乱逻辑来证明重构。

部分相似的判断：类型共有的节拍（相遇、警告、代价、挽回）可以相同；两条以上关键节拍不仅位置相同、而且**由同一个原因导向同一个结果**时，视为没有重构。

结尾前的那次揭示也要换渠道。原作若靠“读到一行事先不知道的字”完成最后一转，新稿可以让它由人物说出、由行为后果呈现或由他人告知。保留揭示带来的信息，不保留同一套解谜动作。

## 写前改编卡

动笔前完成以下内容，每项一到三行。默认不交付，长篇时并入[承接记录](adaptation-state.md)：

```text
档位：
锁定项：
核心类型与必保条件：
必保机制（对象/触发/次数/代价/限制/解除）：
名称与载体映射：
新设定（时代、行业、空间、权力结构）：
角色功能分配（合并/拆分/重分配）：
新事件链决定节点：
去标签对照（每个原决定节点 → 新节点为何不同）：
未知项与待确认：
```

只追踪必须保住的机制、情感作用和已承诺的回报，用最短的“原功能与来源 → 新行动 → 正文结果”来核对，不为每个原场面找对应。

## 返修与跨批承接

返修先读已采用版本，确认这次改变什么、保留什么。名称、功能分配、关系、规则、身份、时间、物件、地点或场序发生变化后，沿引用、说明、触发、人物知识、策略、后果、铺垫与兑现检查依赖，并更新正文和承接记录。效果类要求以正文的实际变化来核对。与改动无关的内容沿用；局部返修不扩成全稿重构。

长篇区分已提供、已读、已改与本次交付范围。跨章删合前，先核对已提供后文的依赖；无法核对时，采用兼容已知功能的新名称与载体，保留未知条件，暂缓会破坏依赖的删合或规则改动，其余部分照常推进。

需要分批时交付连续的场面并标明停止位置，不用摘要代替后半部分。目标体量与保留项冲突时，说明具体的保留、压缩或延长取舍，不靠加快语速假装解决。承接记录的格式见 [adaptation-state.md](adaptation-state.md)；记录不能替正文补因果。
