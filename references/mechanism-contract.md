# 故事核心、机制与重构边界

## 保留的是功能与因果

- **核心**：人物为何非做不可、主要冲突、关键选择和情感驱动，以及观众等待的兑现。不能只留一句主题而丢掉实际事件。
- **机制**：使选择产生特定后果的规则、资源、关系和信息约束，以及悬念、反击、升级或关系变化的推进方式。
- **实现**：人物组合、局部事件、场所、道具、场序和表达方式。可以重做，但承担关键因果的细节应保住功能及必要条件。

同样是配角，重复传递信息的可以合并，必须独立作证的就不能只因戏份少而合成一人。证据取得与生效、能力获得与可使用范围、受损与能否恢复，也可能是不同条件，不能合并省略。

## 按需辨认约束

以下是检查维度，不是必填字段。只记录影响当前任务的项，保留可定位的来源：

| 维度 | 需要辨认的内容 |
| --- | --- |
| 选择与承诺 | 人物在什么选项间决定，观众期待何种结果 |
| 规则与边界 | 适用对象、触发、反馈、次数、限制、解除条件；提供信息的种类与精度 |
| 代价与回报 | 谁承担损失、能否恢复、如何兑现，推进或升级怎样发生 |
| 知识与视角 | 谁知道什么，观众何时得知，哪些仍是猜测 |
| 依赖与来源 | 哪个事件铺垫后果；对应原文位置、推断或新增改编 |

没有页码或章节号时，用独特事件定位，不编引文。已知事实、人物口述、猜测和未知答案分别处理。信息顺序维护的是知识边界与悬念逻辑，不必锁死原著时间线。

感知或证据工具的画面细节也受信息上限约束。不能为了写得具体，加入其不能显示的纹理、身份或时间信息，再据此推进判断。

若原文有不兼容的说法，先判断是不可靠口述、未揭示例外还是真正冲突。能在已授权范围内兼容时采用最小改法；不能兼容且决定核心时，指出具体冲突再集中询问，不偷偷增设有利规则。

## 重构与取舍

默认可压缩或扩展场面、改写对白、合并重复功能角色、重做支线和局部冲突、调整背景与场序。保留核心承诺的兑现方向、性质与必要代价；用户明确开放的项目按新约定处理。忠实改编请求则进一步保留其指定人物关系、核心事件和结局。

普通衔接动作与线索可以主动创作，但须兼容已知材料。重大新增不应跨越未读后文的知识缺口。无需为普通创作逐项请示，或为显得不同而更名换景。

大改或高影响删合时，用最短的**原功能与来源—新行动—正文结果**对应核对关键变化。例如工作记录可写：

| 原功能与来源 | 处置与新行动 | 正文结果及依赖 |
| --- | --- | --- |
| 某场用试探迫使对方暴露立场 | 合并到另一场，改用新环境中成立的筹码 | 对方改变策略；保留后文误判所需的信息边界 |

只需覆盖关键选择、规则、筹码、代价和兑现的高影响变化。处置可为保留、合并、删减或外化；一条工作笔记也可，不强制逐场填表或交付报告。

新行业、时代或载体要重新成立能力范围、权力、资源和行为后果，不能只把职业和道具替名，再沿用旧环境的解决方式。避免为了保住原动作扩大能力；重做冲突时仍保留人物独特的情感驱动与表达。作品新增制度按作品内约定呈现，不冒称现实通行事实。

明确的永久损失不可弱化为暂未恢复。但永久性首先是叙事后果，可由不可撤销的选择、持续失效、规则结算或后续生活呈现；不规定必须用诊断、宣告或解释台词证明。

## 返修：检查变化的影响

1. 读取已采用版本和用户新要求，确认改变项及继续保留项。明确的新约定直接替换旧项。
2. 对规则、身份、时间、物件或场序变动，沿说明、触发、人物知识、策略、后果、铺垫和兑现检查受影响场面；沿用无关内容，不从头重做项目。
3. 对“更主动”“更紧张”等效果型要求，核对场面实际变化。试探可以失败，反馈仍应影响其策略、成本、对方或信息局面；只增加问句和分析未必达到效果。停顿与余波不必强行推进。
4. 更新承接或改编记录中的受影响项，不能只改正文而继续以旧规则处理后文。记录不能替正文补因果。

完整稿、局部替换稿及说明的范围按用户要求，具体交付见 [script-format.md](script-format.md)。

## 长篇范围与承接

区分已提供、已读、已改编和本次交付范围。拿到一章不等于知道全书；摘要不等于读过原著。后文已提供但尚未核对，也不能视为已知。

可能影响跨章机制的人物、物件或线索，先核对已提供后文依赖；无法核对时暂不作这类高影响删合，其他可完成的改编继续。无需全书逐字通读后才写第一场。

未要求压缩时不自动改成几分钟短剧。体量需分批时，完成连续可交付场面，明确停止位置，不能用摘要充当后半部剧本。目标体量与保留项冲突时，先完成可做的阅读与梳理，再给具体保留、压缩或延长的取舍，不用提高语速假装解决。

跨批复用现有记录，按需更新：已读与已改范围、下一段起点、核心规则与未知项、人物映射和已采纳改动、角色知识及物件状态、未兑现铺垫和待核假设。保存到项目允许的工作目录；无文件工具时精简附后。用户只要正文且有文件工具时另存记录，不额外塞入正文。
