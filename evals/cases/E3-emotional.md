# E3 情感与关系：《浮生六记·闺房记乐》C 档改编

**素材**：沈复《浮生六记》第一卷（公有领域）。可只提供“初识—成婚—清贫相处”段落。

**要点**：沈复与芸娘少年相识、婚后清贫而相得，芸娘为丈夫寻妾、遭家中排挤；后期芸娘病逝。情感来自相处的具体细节与共同承担的代价。

## 给模型的请求

```text
把《浮生六记》里沈复和芸娘的部分改编成剧本，换掉人名地名和时代背景，重做人物关系，保留这个故事打动人的地方。直接写。
```

## 硬检查点

1. **情感通过互动与之后的行为变化成立**，不靠旁白或人物直述“我们很恩爱”。
2. 双方各有当下诉求，芸娘一侧不能只作为照顾者和配合者；她的选择有自己的理由。
3. 清贫或家族压力**实际影响选择、相处或后续生活**，不只是背景介绍。
4. 关系变化（亲近、隔阂、误会、和解）之后，**后续场次的行为有相应改变**。
5. C 档去标签后，按四个维度（决定节点、关系网、信息揭示、解决方式与结尾）核对，至少三项是新稿自己的，不能逐项对回原作。
6. 新设定中的权力与资源约束成立（不与新环境冲突，如保留旧式大家族制度却不给其在新时代的对应基础）。

## 观察项

- 是否自发选择新载体（如当代或近世的普通生活），而非自动落入“民国旧家庭”。
- 是否给结尾留出余波。

## 常见失败

- 只把名字改成现代名，保留原事件的每一步。
- 把压力写成恶人加害，丢掉日常性。
- 用一段煽情独白代替代价。
