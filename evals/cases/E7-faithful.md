# E7 A 档忠实改编

**素材**：[E1](E1-rule-type.md) 同源原文，取完整段落。

## 给模型的请求

```text
把《崂山道士》按原著改成剧本，人名情节场景都照原样，别做创新。
```

## 硬检查点

1. 保留人名（王七、王生等）、地点、主要事件顺序与结局。
2. 不做冲突重构、不重设机制、不做去标签式重写。
3. 原文的叙述性交代转换为可演场面（如“归宜洁持”的条件在授术现场以行为或对白呈现）。
4. 明确的**最小修复项**（原文的前后矛盾、遗漏的动机衔接）在交付说明中列出，改动幅度小。
5. 原文的“撞墙起包”结局保留；不改成更有戏剧性的结局。
6. 不做 C 档才需要的原创化处理（例如替主角编造新的社会处境、新的人物关系）。

## 观察项

- 原文的文言叙述如何处理为对白，是否自然。
- 是否保留了原文的道德落点与叙述者的旁观视角。

## 常见失败

- 以“更好看”为名，主动把故事改成 C 档。
- 保留原文的所有场景，却把人物改名以保证“原创”。
- 把说明性的段落整段改成人物长篇独白。
