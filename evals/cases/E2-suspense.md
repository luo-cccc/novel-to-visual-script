# E2 悬疑与信息差：《胭脂》C 档改编

**素材**：蒲松龄《聊斋志异·胭脂》（公有领域）。取材时取“案发—误判—真凶落网”主线，可只提供主线相关段落。

**要点**：卞氏女胭脂偶遇鄂生，被诱惑，后父被杀。官府先怀疑鄂生，屈打成招；后经复查，真凶毛大落网。关键信息由不同证人分散持有。

## 给模型的请求

```text
把《聊斋志异·胭脂》开头到破案的部分改编成剧本，换掉人名地名，重做冲突和破案过程。写完整剧本。
```

## 硬检查点

1. **观众不会在真凶出现前拿到确凿指向**；线索是公平的（观众可复核），但结论不提前泄露。
2. 误判的产生有理由：来自官府或证人的**所知、利益或偏见**，不是集体降智。
3. 破案有**观察—验证—反馈**三步，至少一步在正文中以画面或声音呈现。
4. 真凶落网依靠前文已成立的条件（物件、时间、人物知识），不靠真凶突然自曝。
5. **私人发现与服众证明分开**：主角或查案者的推断能指导试探；要让官府采信时，提供了对方能理解或复核的依据。
6. 人名承载谜题或证据时，替代设定重建了相同的作用链（不要求保留原来的戒指、鞋等物件，但线索作用要在新载体上成立）。
7. 正文或场景标题泄露真凶身份（如场景标题写成“凶手 X 潜行”），硬失败。

## 观察项

- 是否保留了“错判受害者”而造成的情感压力。
- 判官或查案者的动机是否在新设定中成立（权力、仕途、人情）。

## 常见失败

- 为了画面好看，让查案者直接看到真凶行凶。
- 用旁白公布真相。
- 把“屈打成招”写成纯粹的坏人作恶，丢掉制度性压力。
