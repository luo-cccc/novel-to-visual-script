# E9 对白与声音：《婴宁》C 档改编

**素材**：蒲松龄《聊斋志异·婴宁》（公有领域）。可只提供“王子服寻访婴宁—园中相会—归家成婚”段落，并在提问里说明范围。

**要点**：王子服上元节遇见爱笑的少女婴宁，相思成病，独自寻访山中，在园中与她相会；婴宁言语天真，答非所问，王子服示爱时她装作不懂。人物性格大量靠对白呈现，适合检验对白与声音区分。

## 给模型的请求

```text
把《聊斋志异·婴宁》里王子服寻访婴宁到带她回家这一段改编成剧本，换掉人名地名，人物关系和冲突重新设计。写完整剧本。
```

## 硬检查点

1. **遮名可辨**：遮住人名后，至少两个主要人物的台词可以分辨，差异来自目的、所知、句式或回避方式，而不是只靠口头禅或方言词。
2. **无说明书式对白**：没有人物独处时把计划或心理逐条说出，没有人物向对方复述双方都已知道的往事来交代背景。
3. **无情绪播报**：关键情绪不靠“我很难过”“我好想你”一类直陈完成，至少有一处由动作、停顿或二次动作呈现。
4. **示爱或试探的戏有潜台词**：至少一场关键交锋中，人物不直说真意，观众仍能从前文锚点读懂。
5. **人物只回应自己听见、看见、知道的**：没有人物回应未在场听到的台词，或使用只有观众知道的信息。设定内的超自然知情（如预知）若在正文中作为异样被其他人物或观众察觉，不算越界；没有交代、只是作者疏忽的，算失败。
6. **核心保住**：原作“天真之笑掩盖的来历与处境”的吸引力仍在，没有被改成单纯的甜宠或单纯的恐怖。

## 观察项

- 场尾是否大多落在感悟、承诺或金句上。
- 惯用反应（攥拳、深吸一口气、眼眶泛红等）出现的次数。
- “不是……而是……”等翻案句式在叙述和对白中的频率，以及是否有功能。
- 是否为了“丰富”而给本该简短的台词硬加动作和潜台词。

## 常见失败

- 女主角的天真写成一组固定的口头禅，换掉名字后与其他少女角色无法区分。
- 用一段内心独白把男主角的相思直接讲完。
- 每场结尾都由某个人物总结这场戏的意义。
